CheatX

Detect plagiarism in C programming assignments with accuracy & transparency.

CheatX analyzes source code using structural, syntactic, and control-flow heuristics to identify suspicious similarities between student submissions.

Get Started

About CheatX

Academic dishonesty in programming assignments is a growing concern. Simple string comparison or naive diff tools fail to detect plagiarism when students rename variables, change formatting, or restructure their code.

CheatX was built to solve this challenge. Written in Python, it detects similarities between C language source files by examining deeper program structures, control flow, and function-level features. It provides both a detailed log of the analysis and a final plagiarism report with certainty percentages.

Key Features

  • Bind Score Analysis – calculates heuristic similarity scores based on variables, functions, keywords, and libraries.
  • Control Flow Simulation – simulates program execution by analyzing curly brace scopes to compare logical flow.
  • Automated Clustering – groups potentially plagiarized files into clusters for side-by-side analysis.
  • Report Generation – produces LOG_REPORT.txt (step-by-step process) and FINAL REPORT.txt (plagiarism results).
  • User-Friendly UI – a simple Tkinter interface allows users to provide a dataset path and generate reports instantly.

How It Works

  1. Stage 1 – Bind Score: Each file is analyzed for variables, functions, keywords, and libraries. A numeric score is computed.
  2. Stage 2 – Clustering: Files with similar bind scores are grouped together for deeper comparison.
  3. Stage 3 – Walkthrough Simulation: The control flow of each file is simulated and compared within clusters.
  4. Report Generation: Results are compiled into detailed log and final outcome reports, including certainty percentages.

Usage Instructions

Prerequisites:

  • Python 2.x/3.x
  • Tkinter library (for GUI)
  • C source files as test data

Steps:

  1. Clone the repository: git clone https://github.com/YourUsername/CheatX.git
  2. Navigate to the project folder: cd CheatX
  3. Place your C source files inside the testData directory.
  4. Run the program: python main.py
  5. Enter the path when prompted and click Generate Report.
  6. Check LOG_REPORT.txt for analysis logs and FINAL REPORT.txt for plagiarism results.
